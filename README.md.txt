## 🌟 نبذة عن المشروع

تطبيق **«الذكي»** هو دفتر تحضير وإدارة مدرسية رقمي يعمل كـ **تطبيق ويب تقدمي (PWA)**، تم تصميمه ليعمل بكفاءة عالية على مختلف الأجهزة (الهواتف، الآيباد، وأجهزة الحواسيب) حتى عند **عدم توفر الاتصال بالإنترنت**. 

يعتمد التطبيق على معالجة طرف العميل (Client-Side) مع إمكانية ربطه المباشر بـ **Gemini API** لتحويل المحتوى التعليمي والكتب المدرسية من صور وذواكر PDF إلى خطط دراسية، سبورات تعليمية، ملخصات تفاعلية، وااختبارات مبوبة تلقائيًا.

## 🚀 المميزات الرئيسية

### 1. ✏️ تحضير سحري ومتعدد المصادر
* **الاستخراج الذكي (OCR & PDF):** مسح صور الكتاب المدرسية وقراءتها بذكاء اصطناعي فائق مع دعم كامل للمعادلات والرموز الرياضية.
* **التحضير عبر العناوين:** إمكانية الابتكار والتوليد الآلي للخطط الدراسية حتى عند عدم توفر النص الأصلي.
* **أدوات تعزيز التدريس:** 
  * 🌍 ربط الدرس بالواقع وتطبيقاته الحياتية.
  * 👨‍🏫 إرشادات الموجه الشخصي واقترحات الاستراتيجيات الحديثة.
  * 🧠 بناء وتصدير الخرائط الذهنية البصرية.
  * 📝 حل تقويم الوحدة وإعداد نماذج الإجابة.

### 2. 🖍️ التصدير والوسائط الفائقة
* **سبورات وشرائح عرض:** إنشاء عروض تقديمة وسبورات درسية مع تنسيقات جاهزة للطباعة القياسية (A4).
* **صوت وفيديو حركي:** كتابة حوارات تعليمية وتوليد مقاطع صوتية أو تصديرها كملفات فيديو حركية (Typewriter Effect) تعمل أوفلاين.
* **مشاركة HTML مستقلة:** تصدير ملخصات واختبارات تفاعلية في ملف واحد خفيف يدعم خاصية نطق اللغات (TTS) بدون الحاجة للإنترنت لدى الطالب.

### 3. 🗄️ بنك الدروس والاختبارات التفاعلية
* **بنك أسئلة مبوب:** فرز وتوزيع الأسئلة والوزاريات حسب وحدات وفصول الكتاب.
* **محرر الاختبارات المتقدم:** توليد اختبارات ورقية، تفاعلية، وواجبات منزلية.
* **نظام القرعة الشفوية:** اختيار عشوائي للطلاب وعرض أسئلة شفوية مخصصة مع ترحيل الدرجة تلقائيًا لدفتر الدرجات.

### 4. 📈 التقييم والإحصائيات
* **استمارة التقييم الذاتي الموحدة:** مطابقة للزيارات الصفية الرسمية مع حاسبة درجات تلقائية.
* **لوحة إحصائيات شاملة:** متابعة المنجزات والملفات والدروس المحفوظة.
